## How I work with AI

- I spend time staying up to date with the latest developments and official recommendations concerning agentic coding best practices
- I talk through architecture and design decisions with the AI before implementing, so I understand them instead of just accepting them. For this I use Claude Code's plan mode
- Features are planned as GitHub Issues and Milestones, which Claude creates through the GitHub CLI
- Agents run in isolated dev containers / GitHub Codespaces
- Branch protection: `main` is protected by GitHub Rulesets and repository settings, so changes only land through pull requests
- I review and merge the generated PRs
- PR verification is supported by GitHub Workflows (CI with tests, linters, security scanners, etc.)

The reusable setup lives in [agentic-coding-templates](https://github.com/Felix-Muellner/agentic-coding-templates).
