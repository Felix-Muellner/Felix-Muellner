## How I work with AI

I build with Claude Code, use whichever tech stack fits the project, and keep up with official agentic-coding recommendations.

- I discuss architecture and design with the AI before implementing, using Claude Code's plan mode, so I understand decisions instead of just accepting them
- Features are planned as GitHub Issues and Milestones, and agents run in isolated dev containers / GitHub Codespaces
- `main` is protected by GitHub Rulesets, so changes only land through pull requests that I review and merge
- CI runs tests, linters and security scanners on every PR
